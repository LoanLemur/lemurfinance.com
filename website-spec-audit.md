# Website Specification audit

**Audit date:** 2026-07-21

**Last updated:** 2026-07-22

**Coverage:** Foundations, SEO, and Accessibility

**Source:** [The Website Specification](https://specification.website/), using its complete category checklists and topic pages as the audit authority.

This is the running audit for the current Astro site and its static production build. Statuses describe the repository after the fixes in this audit:

- **compliant** — verified in source or generated HTML
- **fixed** — corrected in this audit and verified in the generated build
- **needs verification** — requires a deployed response, browser, assistive technology, or real-device check
- **human action** — needs an approved asset or stakeholder decision
- **not applicable** — the site has no feature or content to which the item applies

## Outstanding verification and human decisions

### Human action

1. When assets are available, approve and export the complete favicon/PWA icon set, including a real multi-resolution ICO, Apple touch icon, 192px/512px icons, a maskable icon, and manifest details.
2. When assets are available, approve a stable, on-brand Open Graph image; then add `og:image`, its real dimensions, and social-preview validation.
3. Review the LeadConnector contact form's privacy and accessibility settings. Its cross-origin document currently lacks a `lang` attribute, disables viewport scaling, and loads Google Fonts plus provider tracking scripts; these cannot be corrected from the parent Astro page.

### Production and runtime verification

1. Verify preferred-host, HTTPS, trailing-slash, and legacy URL redirects are single-hop permanent redirects; verify unknown URLs return a real 404.
2. Verify production `robots.txt`, `sitemap-index.xml`, and generated sitemap status/content types, canonical targets, robots headers, and staging/preview `noindex` behavior.
3. Run deployed Schema.org/Google validation and social preview debuggers after approved imagery is added.
4. Complete keyboard-only, visible-focus, touch-target, light/dark contrast, forced-colors, zoom, and real-device checks on all four templates. Include the entire embedded contact form, its validation errors, consent controls, and one end-to-end test submission.
